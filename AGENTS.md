# Pointed

Pointed is an iOS-first scoreboard built with Expo, React Native,
Expo Router, TypeScript, and SQLite.

## Global rules

- Maintain Expo Go compatibility.
- Use TypeScript.
- SQLite is the persistent source of truth.
- Preserve existing functionality unless a task explicitly changes it.
- Do not add dependencies unless necessary.
- No backend, analytics, authentication, ads, or tracking.
- Maintain light/dark mode.
- Maintain accessibility.
- Prefer small targeted changes over broad refactors.
- Run available type and lint checks after implementation.
- Never commit or push unless explicitly requested.
